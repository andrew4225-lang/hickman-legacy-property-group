HICKMAN LEGACY PROPERTY GROUP — WEBSITE STARTER

Files:
- index.html: website content
- styles.css: responsive styling
- script.js: mobile navigation and contact form

IMPORTANT BEFORE PUBLIC LAUNCH
1. In script.js, replace YOUR-EMAIL@example.com with the business email address.
2. The contact form opens the visitor's email app; it does not store or transmit leads on a server.
3. The property photos are loaded from Unsplash and need an internet connection.
4. This is a static website and can be deployed with GitHub Pages or Vercel.

QUICK DEPLOY (Android)
1. Open https://github.com/new and create a repository named hickman-legacy-property-group.
2. In the new repository, choose Add file > Upload files.
3. Upload index.html, styles.css, and script.js (upload the files inside this folder, not the ZIP itself).
4. Commit the files.
5. For Vercel: open https://vercel.com/new, import the repository, keep the default settings, and press Deploy.
6. Vercel will give you the public website URL after the deployment finishes.

No passwords, API keys, or database credentials are needed for this static starter.
